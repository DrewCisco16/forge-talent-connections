## 10. AGENT PLACEMENT GUIDANCE

**Everything in this section is a Recommendation, not a fact.** It is reasoning from the hardware above, not from any tested benchmark.

### 10.1 The load-bearing principle

Cloud-executed agents do not need a machine powered on. Claude Code Routines execute on Anthropic-managed infrastructure. OpenAI Codex tasks run in per-task cloud sandboxes preloaded with the repository. **Any 24/7 agent that can run in a vendor cloud should run there, not on local hardware.** Local nodes are for work that cannot leave the premises, needs a GPU, needs a specific OS, or needs a physical device attached.

### 10.2 Suggested node assignment

| Workload class | Node | Reason |
|---|---|---|
| Unattended multi-hour orchestration, overnight loops | HP Envy 17 | 64GB, already designated, WSL2 for real bash |
| Local LLM inference, embeddings, CUDA | ASUS ProArt 16 | Only GPU |
| Apple platform builds, Xcode, TestFlight | MacBook Air 15 M4 | Only Mac |
| Touch, pen, and tablet-layout QA | Surface Pro 8 | Only touchscreen Windows |
| Anything cloud-executable | Vendor cloud | No local dependency, survives lid closing |
| Physical device testing | The five phones, iPad, two watches | Requires the hardware in hand |

### 10.3 Hard constraints any agent designer must respect

1. **The MacBook Air at 16GB is the fleet bottleneck.** Do not design an Apple-platform workflow that assumes simultaneous Xcode, Android Studio, Docker, and multiple terminals.
2. **The RTX 5070 has 8GB VRAM.** That sets the ceiling on locally hosted model size.
3. **Windows nodes need explicit sleep prevention** before any unattended run. See 1.1.
4. **Displays are site-bound.** Two workstations sit in the home office upstairs and one sits at the Doral office. A workflow that assumes a multi-monitor layout is only valid when Andrew is physically at that desk. Travel work runs on a single laptop panel.
5. **GovCon compliance boundary.** Any workload touching CUI or contract-restricted data cannot be routed through third-party cloud agent infrastructure without a contracts-counsel review. This is a legal question, not a hardware question. **Professional verification required.**
6. **Lane separation.** GovCon, software company, DBA, and personal administration are separate lanes. Agents must not cross-use information between lanes without explicit authorization from Andrew.
