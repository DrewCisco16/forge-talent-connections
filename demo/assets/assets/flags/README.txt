Service flag artwork for the A4 Veteran Verification screen.

Drop one image per branch, named by id:
  usmc.png  usa.png  usn.png  usaf.png  uscg.png  ussf.png

Roughly 3:2 landscape, 600px+ wide. The screen shows each file automatically;
until a file exists, the card falls back to the branch's authentic flag color.
This container cannot reach public flag image repositories, so the artwork
must be supplied.
